# The Unread Manifesto

**A case for Policy-Driven Development.**

Software quality has never depended on someone reading every line. It depends on a system that guarantees what comes out is good.

Read it at **[theunread.dev](https://theunread.dev)**.

## Sign it

Use the form at [theunread.dev](https://theunread.dev/#sign) (it opens a pull request for you), or open a pull request adding your name to [SIGNATORIES.md](SIGNATORIES.md). One line, at the end of the list:

```
- Your Name, Role or Company (optional), City or Country (optional)
```

## Propose a change

The manifesto is meant to evolve. If you think something is wrong, missing or unclear:

- Open an [issue](../../issues) to discuss it, or
- Open a pull request editing `index.html` with your proposal and the reasoning behind it.
